## 设计理念

### 核心思想

> **"函数即卡牌，对象即棋子，调用即出牌。"**

本游戏将 C++ 语言的核心特性具象化为牌桌对战的各个元素：

| 编程概念 | 游戏映射 |
|---------|---------|
| 类 `Player` | 玩家本体 |
| 对象 `Player A` | 初始代表玩家的实例 |
| 成员函数 | 攻击/受击/逃跑等函数牌，打出后修改函数定义 |
| 构造函数 | 召唤仆从 |
| 复制构造函数 | 复制仆从 |
| 移动构造函数 | 转移资源、复活 |
| 析构函数 | 献祭仆从触发亡语 |
| 模板 | 模板牌——包装/增强其他函数牌 |
| 运算符重载 | 融合/分裂/强化牌 |
| 虚函数/多态 | 进化系统 |
| 异常处理 | 命运牌——高风险高回报 |
| Lambda | 一次性临时效果牌 |
| RAII | 增益/减益自动管理 |

### 重要区分

| | 函数牌 | 行为牌 |
|:-:|:------:|:------:|
| 本质 | 修改代码 | 执行动作 |
| 类比 | 升级装备、修改技能 | 使用技能攻击 |
| 效果 | 永久/长期改变成员函数 | 一次性效果 |
| 例子 | `攻击函数·吸血` 让 `attack()` 永久吸血 | `全力一击` 本回合打出一次强化攻击 |

## 核心架构：双层卡牌体系

### Player 类的框架

```cpp
class Player {
public:
    // 成员函数（可被函数牌替换/升级）
    virtual void attack(Enemy& target);         // 攻击函数
    virtual void takeDamage(int dmg);           // 受击函数
    virtual Minion summon();                    // 构造函数（召唤）
    virtual Minion copySummon(const Minion&);   // 复制构造函数
    virtual Minion moveSummon(Minion&&);        // 移动构造函数
    virtual void sacrifice(Minion& m);          // 析构函数（献祭）
    virtual bool escape();                      // 逃跑函数

    // 基础动作（每回合可用，次数有限）
    void basicAttack(Enemy& target);            // 调用当前 attack()
    void basicDefend();                         // 调用防御模式
    void basicSummon();                         // 调用当前 summon()
    bool tryEscape();                           // 调用当前 escape()
};
```

### 卡牌分类体系

```
卡牌体系
├── 函数牌 — 修改/升级 Player 的成员函数
│   ├── 攻击函数牌（升级 attack()）
│   ├── 受击函数牌（升级 takeDamage()）
│   ├── 构造函数牌（升级 summon()）
│   ├── 复制构造牌（升级 copySummon()）
│   ├── 移动构造牌（升级 moveSummon()）
│   ├── 析构函数牌（升级 sacrifice()）
│   └── 逃跑函数牌（升级 escape()）
│
├── 行为牌 — 一次性实际执行动作
│   ├── 攻击行为（额外攻击、横扫等）
│   ├── 召唤行为（紧急召唤、快速复制等）
│   ├── 献祭行为
│   └── 特殊行为（重写、重载、变身等）
│
└── 模板牌 — 包装/组合函数牌的"框架"
    ├── Triple<F> — 三连击
    ├── IfElse<C,F1,F2> — 条件分支
    └── Recurse<N,F> — 递归展开
```

## 指令牌详解

> 指令牌是实际执行动作的卡牌，与函数牌（修改代码）不同，指令牌直接调用当前版本的成员函数。
>
> **二者的协作关系**：先用函数牌升级 `attack()`，再用指令牌执行攻击，打出的就是升级后的效果。

### 基础指令（每回合免费使用，次数有限）

基础指令是每回合默认拥有的基本行动能力，无需占用卡牌位置。

| 指令名称 | 效果 | 每回合可用次数 |
|:--------:|:----|:--------------:|
| **攻击指令** | 调用当前 `attack()` 对指定敌方目标进行一次普通攻击 | 一次 |
| **防御指令** | 进入防御姿态，本回合受到的伤害降低 | 一次 |
| **召唤指令** | 调用当前 `summon()` 创建一个基础仆从 | 一次 |
| **复制指令** | 调用当前 `copySummon()` 复制一个己方仆从 | 一次（需函数牌解锁）|
| **转移指令** | 调用当前 `moveSummon()` 转移一个仆从资源 | 一次（需函数牌解锁）|
| **献祭指令** | 调用当前 `sacrifice()` 献祭一个己方仆从 | 一次（需函数牌解锁）|
| **逃跑指令** | 尝试调用当前 `escape()` 逃离战斗 | 整场战斗一次 |

> **说明**：基础指令调用的是 Player 当前版本的成员函数。若已打出攻击函数·强化，则攻击指令将自动造成强化后的伤害。

## 模板牌详解

> **模板牌的本质**：一个 C++ 模板容器，将函数牌"塞入"后，对函数进行包装/增强。

### 模板牌 1：三连击 `Triple<Func>`

**C++ 对应**：循环展开 / 函数调用多次

```cpp
template<typename Func>
class Triple {
    Func func;
public:
    Triple(Func f) : func(f) {}

    void execute(auto& player, auto& target) {
        func(player, target);
        func(player, target);
        func(player, target);
    }
};
```

| 组合示例 | 效果 |
|:--------|:-----|
| `Triple<攻击函数·强化>` | 攻击函数连续攻击多次，每次均享受增益 |
| `Triple<构造函数·强化>` | 一次召唤多个强化仆从 |

| 费用 | 稀有度 |
|:----:|:------:|
| 较高 | 稀有 |

### 模板牌 2：条件分支 `IfElse<Cond, Func1, Func2>`

**C++ 对应**：`条件 ? 表达式1 : 表达式2` 三目运算符

```cpp
template<typename Cond, typename Func1, typename Func2>
class IfElse {
    Cond condition;
    Func1 onTrue;
    Func2 onFalse;
public:
    void execute(auto& player, auto& target) {
        if (condition(player, target))
            onTrue(player, target);   // 条件满足
        else
            onFalse(player, target);  // 条件不满足
    }
};
```

| 组合示例 | 效果 |
|:--------|:-----|
| `IfElse<生命充足, 攻击函数·强化, 受击函数·铁壁>` | 状态好则进攻，状态差则防守 |
| `IfElse<敌方有增益, 复制构造·精准, 构造函数·量产>` | 视敌方状态决定复制或量产 |

| 费用 | 稀有度 |
|:----:|:------:|
| 中等 | 稀有 |

### 模板牌 3：递归展开 `Recurse<N, Func>`

**C++ 对应**：模板元递归 + `if constexpr` 编译期展开

```cpp
template<int N, typename Func>
class Recurse {
    Func func;
public:
    void execute(auto& player, auto& target) {
        apply<N>(player, target);
    }

private:
    template<int Depth>
    void apply(auto& player, auto& target) {
        if constexpr (Depth > 0) {
            func(player, target);
            apply<Depth - 1>(player, target); // 递归
        }
    }
};
```

| 组合示例 | 效果 |
|:--------|:-----|
| `Recurse<N, 攻击函数·连击>` | 递归调用连击，总攻击次数倍增 |
| `Recurse<N, 构造函数·量产>` | 递归召唤，产出大量仆从 |

| 费用 | 稀有度 |
|:----:|:------:|
| 高昂 | 传说 |

## 游戏流程示例

```
回合开始
【手牌】  [攻击函数·强化] [受击函数·反伤] [三连击] [全力一击]
【能量】  充足
【生命】  健康
【仆从】  (无)

第 1 回合
- 打出 [攻击函数·强化]，消耗部分能量
  -> attack() 得到升级，伤害提升
- 基础动作：攻击
  -> Player.attack(敌方) 造成增强后的伤害
- 能量不足以打出 [三连击]，跳过

第 2 回合
- 抽牌获得 [构造函数·精锐]
- 打出 [构造函数·精锐]，消耗部分能量
  -> summon() 升级为召唤精锐仆从
- 基础动作：召唤
  -> 召唤一个精锐仆从
- 基础动作：攻击（仆从攻击）
  -> 仆从攻击敌人

第 3 回合 — 决胜时刻
- 生命值降低，局势紧张
- 将 [攻击函数·强化] 塞入 [三连击] 形成组合牌
- 打出组合牌 Triple<攻击函数·强化>
  -> 本回合 attack() 变为连续多次攻击
- 打出 [全力一击]
  -> 立即 attack() 且伤害大幅提升
  -> 多次攻击叠加全力一击，造成巨额总伤害
- 敌方首领被击败
```
